  - 'M(N,Z) = N M_n + Z M_p - B c^2'
  - 'M(N,Z) = N M_n + Z M_p + B c^2'
answers:
  - 'M(N,Z) = N M_n + Z M_p - B/c^2'
---

**$M_p$ என்பது புரோட்டானின் நிறையையும் $M_n$ என்பது நியூட்ரானின் நிறையையும் குறிக்கும். $Z$ புரோட்டான்களும் $N$ நியூட்ரான்களும் கொண்ட அணுக்கரு ஒன்றின் பிணைப்பாற்றல் $B$ எனில் அவ்வணுக்கருவின் நிறை $M(N,Z)$ ஆனது: (இங்கு $c$ என்பது ஒளியின் வேகம்)**

```markdown
அணுக்கருவின் பிணைப்பாற்றல் ($B$) என்பது அதன் நிறை குறைபாட்டிற்குச் ($\Delta m$) சமமான ஆற்றல் ஆகும்.

நிறை குறைபாடு என்பது தனித்தனி நியூக்ளியான்களின் (புரோட்டான்கள் மற்றும் நியூட்ரான்கள்) மொத்த நிறைக்கும், ஒன்றாக இணைந்த அணுக்கருவின் உண்மையான நிறைக்கும் ($M(N,Z)$) உள்ள வேறுபாடாகும்:

<div class="math-display">$$\Delta m = (Z M_p + N M_n) - M(N,Z)$$</div>


ஐன்ஸ்டீனின் நிறை-ஆற்றல் சமன்பாட்டின்படி ($E = mc^2$), பிணைப்பாற்றல்:

<div class="math-display">$$B = \Delta m \cdot c^2$$</div>


<div class="math-display">$$B = \left[ (Z M_p + N M_n) - M(N,Z) \right] c^2$$</div>


அணுக்கருவின் நிறை $M(N,Z)$-க்கான சமன்பாட்டைப் பெற, மேற்கண்ட சமன்பாட்டை மாற்றியமைக்க வேண்டும்:

<div class="math-display">$$\frac{B}{c^2} = Z M_p + N M_n - M(N,Z)$$</div>



<div class="math-display">$$M(N,Z) = N M_n + Z M_p - \frac{B}{c^2}$$</div>


இதிலிருந்து, ஒரு நிலையான அணுக்கருவின் நிறையானது, அதனை உருவாக்கும் தனித்தனி நியூக்ளியான்களின் மொத்த நிறையை விட $\frac{B}{c^2}$ அளவு குறைவாக இருக்கும் என்பது தெளிவாகிறது. 

சரியான விடை: **M(N,Z) = N M_n + Z M_p - B/c^2**.
```
