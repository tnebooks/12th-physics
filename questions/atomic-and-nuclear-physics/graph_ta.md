**கதிரியக்கத் தனிமம் A இன் அரை ஆயுட்காலம் மற்றொரு கதிரியக்கத் தனிமம் B-இன் சராசரி ஆயுட்காலத்திற்கு சமமாகும். தொடக்கத்தில் அவ்விரண்டு தனிமங்களின் அணுக்களின் எண்ணிக்கை சமமாக உள்ளது எனில்:**

```markdown
கொடுக்கப்பட்டவை:
- A இன் அரை ஆயுட்காலம் (T₁/₂) = B இன் சராசரி ஆயுட்காலம் (τ)

சராசரி ஆயுட்காலம் τ = 1/λ  
அரை ஆயுட்காலம் T₁/₂ = ln(2)/λ

T₁/₂ (A) = τ (B)  
ln(2)/λ_A = 1/λ_B  
λ_B / λ_A = 1/ln(2) ≈ 1.44

எனவே, λ_B > λ_A

சிதைவு வீதம் (decay rate) R = λN.  
தொடக்கத்தில் N_A = N_B எனில்,  
R_B / R_A = λ_B / λ_A = 1.44 > 1

எனவே, R_B > R_A → **B ஆனது A ஐ விட வேகமாக சிதைவடையும்**.

சரியான விடை: **A வைவிட B வேகமாக சிதைவடையும்**
```
