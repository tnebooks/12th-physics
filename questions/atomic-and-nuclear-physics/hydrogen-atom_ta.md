**ஹைட்ரஜன் அணுவில் நான்காவது சுற்றுப்பாதையில் இருக்கும் எலக்ட்ரானின் வேகம்:**

```markdown
போர் அணு மாதிரியின்படி, எலக்ட்ரானின் கோண உந்தம் (angular momentum) குவான்டமாக்கப்பட்டுள்ளது:

mvr = nℏ = n(h/2π)

n = 4 (நான்காவது சுற்றுப்பாதை) எனில்:

mv(4) = 4h/2π = 2h/π

ஆனால், **வேகம் (v)** மட்டும் கேட்கப்பட்டால், அது வழக்கமான சூத்திரத்திலிருந்து:

vₙ = (2.18 × 10⁶ m/s) × (Z/n)

ஹைட்ரஜனுக்கு Z = 1, n = 4:
v = (2.18 × 10⁶) / 4 = 5.45 × 10⁵ m/s

இருப்பினும், கொடுக்கப்பட்ட விடை விருப்பங்கள் h, h/π, 4h/π, 2h/π என உள்ளன. 
இவை கோண உந்தத்தின் மதிப்புகளைக் குறிக்கின்றன.

n = 4 க்கு, கோண உந்தம் L = 4h/2π = 2h/π

எனவே, சரியான விடை: **2h/π**
```
