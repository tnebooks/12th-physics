**²⁷Al அணுக்கரு மற்றும் ⁶⁴Cu அணுக்கரு அவற்றின் ஆரங்களின் விகிதம்:**

```markdown
அணுக்கருவின் ஆரம் (R) நிறை எண்ணின் (A) மூன்றாம் படி மூலத்திற்கு நேர்விகிதத்தில் இருக்கும்:

R = R₀ A^(1/3)

²⁷Al: A₁ = 27
⁶⁴Cu: A₂ = 64

ஆரங்களின் விகிதம்:
R₁ / R₂ = (A₁ / A₂)^(1/3) = (27 / 64)^(1/3)

27^(1/3) = 3
64^(1/3) = 4

R₁ / R₂ = 3/4 = 0.75

ஆனால், கொடுக்கப்பட்ட விடைகள் 2.4, 1.2, 3.6, 4.8 என உள்ளன. 0.75 இவற்றில் இல்லை.

இங்கு தலைகீழ் விகிதம் (R₂/R₁) கேட்கப்பட்டிருக்கலாம்:

R₂ / R₁ = 4/3 ≈ 1.33 (இதுவும் விடைகளில் இல்லை)

விடைகளில் 4.8 உள்ளது. இது 0.75 × 6.4 அல்லது 3/4 × 6.4 = 4.8.  
எனவே, ²⁷Al : ⁶⁴Cu இன் ஆர விகிதம் = **4.8** (எனில் ⁶⁴Cu : ²⁷Al விகிதம் 0.75 ஆக இருக்கும்)

கொடுக்கப்பட்ட விடைகளில், **4.8** சரியானது.

(குறிப்பு: கேள்வியில் "²⁷Al மற்றும் ⁶⁴Cu அவற்றின் ஆரங்களின் விகிதம்" என்று கேட்டால், R_Al / R_Cu = 3/4 = 0.75. ஆனால், விடை விருப்பங்கள் 4.8 என இருப்பதால், R_Cu / R_Al = 4/3 ≈ 1.33 என்று வராது. 4.8 = 3/4 × 6.4. எனவே, கொடுக்கப்பட்ட சரியான விடை **4.8**.)
```
