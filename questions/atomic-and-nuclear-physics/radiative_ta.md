**t = 0 நேரத்தில் அமைப்பு ஒன்றிலுள்ள அணுக்கருக்களின் எண்ணிக்கை N₀. அரை ஆயுட்காலத்தில் பாதியளவு காலம் (t = ½ T₁/₂) ஆகும் போது உள்ள அணுக்கருக்களின் எண்ணிக்கை:**

```markdown
கதிரியக்கச் சிதைவு விதி:  
N(t) = N₀ e^(-λt)

அரை ஆயுட்காலம் T₁/₂ = ln(2)/λ  
λ = ln(2)/T₁/₂

t = ½ T₁/₂ எனில்:

N = N₀ e^(-λ × ½T₁/₂)  
N = N₀ e^(-(ln(2)/T₁/₂) × (T₁/₂/2))  
N = N₀ e^(-ln(2)/2)  
N = N₀ × (e^(ln(2)))^(-1/2)  
N = N₀ × (2)^(-1/2)  
N = N₀ / √2

எனவே, t = ½ T₁/₂ நேரத்தில் மீதமுள்ள அணுக்கருக்களின் எண்ணிக்கை = **N₀/√2**

சரியான விடை: **N₀/√2**
```
