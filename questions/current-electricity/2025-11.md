The first diffraction minimum due to a single slit of width $1.0 \times 10^{-5}\text{ cm}$ is at $30^\circ$. Then the wavelength of light used is:

```markdown
For the first minimum ($n = 1$) in single-slit diffraction:
$$a \sin\theta = n\lambda = \lambda$$

Given:
- $a = 1.0 \times 10^{-5}\text{ cm} = 1.0 \times 10^{-7}\text{ m}$
- $\theta = 30^\circ \implies \sin 30^\circ = 0.5$

$$\lambda = a \sin 30^\circ = 1.0 \times 10^{-7} \times 0.5 = 0.5 \times 10^{-7}\text{ m} = 500 \times 10^{-10}\text{ m} = 500\text{ Å}$$
```
