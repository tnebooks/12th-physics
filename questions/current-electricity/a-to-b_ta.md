**ஒரே நீளமும் மற்றும் ஒரே பொருளால் செய்யப்பட்ட A மற்றும் B என்ற இரு கம்பிகள் வட்ட வடிவ குறுக்குப் பரப்பையும் கொண்டுள்ளன. $R_A$ = 3 $R_B$ எனில் A கம்பியின் ஆரத்திற்கும் B கம்பியின் ஆரத்திற்கும் இடைப்பட்ட தகவு என்ன?**

```markdown
தடை R = ρL/A, இங்கு ρ = தடைத்திறன், L = நீளம், A = குறுக்கு வெட்டுப் பரப்பு.  
பொருள் மற்றும் நீளம் சமம் என்பதால், R ∝ 1/A.  
வட்டப் பரப்பு A = πr² → R ∝ 1/r².  
கொடுக்கப்பட்டது: RA = 3 RB → 1/rA² = 3(1/rB²) → rB² = 3 rA² → rA/rB = 1/√3.  
எனவே சரியான விடை: 1/√3.
```
