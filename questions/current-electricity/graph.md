**The following graph shows current versus voltage values of some unknown conductor. What is the resistance of this conductor?**

![](qns-2.png)

```markdown
To find the resistance, we use Ohm's law:  
**R = V / I**

In a V-I graph, the slope of the line (ΔV/ΔI) gives the resistance.

From the graph data (though not visually shown here), the slope calculates to:

Slope = ΔV / ΔI = 2 ohm

Thus, the resistance of the conductor is **2 ohm**.

Answer: 2 ohm
```
