**230 V மின்னழுத்த மூலத்துடன் இணைக்கப்பட்ட கம்பியில் திறன் இழப்பு P₁. அக்கம்பியானது இரு சமமான பகுதிகளாக வெட்டப்பட்டு இரு துண்டுகளும் பக்க இணைப்பில் அதே மின்னழுத்த மூலத்துடன் இணைக்கப்படுகின்றன. இந்நிலையில் திறன் இழப்பு P₂ எனில் P₂/P₁ எனும் விகிதம்**

```markdown
முதலில் கம்பியின் மின்தடை R என்க.

திறன் P₁ = V² / R  (V = 230 V)

கம்பியை இரு சமமான பகுதிகளாக வெட்டும்போது, ஒவ்வொரு பகுதியின் மின்தடை = R/2.

இரு துண்டுகளையும் பக்க இணைப்பில் (parallel) இணைக்கும்போது, சமான மின்தடை R_eq:
1/R_eq = 1/(R/2) + 1/(R/2) = 2/R + 2/R = 4/R  
R_eq = R/4

புதிய திறன் P₂ = V² / (R/4) = 4V²/R = 4P₁

எனவே, P₂/P₁ = 4/1 = **4**
```
