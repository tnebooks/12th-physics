**In India electricity is supplied for domestic use at 220 V. It is supplied at 110 V in USA. If the resistance of a 60W bulb for use in India is R, the resistance of a 60W bulb for use in USA will be**

```markdown
The power of the bulb is the same in both countries: P = 60 W

Power formula: P = V² / R

For India: P = V₁² / R₁  →  60 = (220)² / R  → R = (220)² / 60

For USA: P = V₂² / R₂  →  60 = (110)² / R₂  → R₂ = (110)² / 60

Now, compare R₂ with R:

R₂ / R = [(110)² / 60] / [(220)² / 60] = (110)² / (220)² = (1/2)² = 1/4

Therefore, R₂ = R/4

The resistance of a 60W bulb for use in USA will be **R/4**.
```
