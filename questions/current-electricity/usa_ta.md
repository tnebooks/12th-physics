**இந்தியாவில் வீடுகளின் பயன்பாட்டிற்கு 220 V மின்னழுத்த வேறுபாட்டில் மின்சாரம் அளிக்கப்படுகிறது. இது அமெரிக்காவில் 110 V அளவு என அளிக்கப்படுகிறது. இந்தியாவில் பயன்படுத்தப்படும் 60 W மின்விளக்கின் மின்தடை R எனில், அமெரிக்காவில் பயன்படுத்தப்படும் 60 W மின்விளக்கின் மின்தடை**

```markdown
இரண்டு இடங்களிலும் மின்விளக்கின் திறன் (Power) ஒன்றுதான்: P = 60 W

திறன் சூத்திரம்: P = V² / R

இந்தியாவில்: P = V₁² / R₁  →  60 = (220)² / R  → R = (220)² / 60

அமெரிக்காவில்: P = V₂² / R₂  →  60 = (110)² / R₂  → R₂ = (110)² / 60

இப்போது R₂ ஐ R உடன் ஒப்பிட:

R₂ / R = [(110)² / 60] / [(220)² / 60] = (110)² / (220)² = (1/2)² = 1/4

எனவே, R₂ = R/4

அமெரிக்காவில் பயன்படுத்தப்படும் 60 W மின்விளக்கின் மின்தடை = **R/4**
```
