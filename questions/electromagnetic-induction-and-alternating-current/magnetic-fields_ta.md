**ஒரு அலைவுறும் LC சுற்றில் மின்தேக்கியில் உள்ள பெரும மின்னூட்டம் Q ஆகும். ஆற்றலானது மின் மற்றும் காந்தப்புலங்களில் சமமாக சேமிக்கப்படும் போது, மின்னூட்டத்தின் மதிப்பு**

```markdown
LC சுற்றில் மொத்த ஆற்றல்:
E_total = Q²/(2C)

மின்தேக்கியில் சேமிக்கப்படும் மின் ஆற்றல்:
E_elec = q²/(2C)

மின்தூண்டியில் சேமிக்கப்படும் காந்த ஆற்றல்:
E_mag = ½LI²

கொடுக்கப்பட்டுள்ளது: E_elec = E_mag

E_elec = E_total/2

q²/(2C) = [Q²/(2C)] / 2 = Q²/(4C)

q² = Q²/2

q = Q/√2

எனவே, மின்னூட்டத்தின் மதிப்பு = **Q/√2**

சரியான விடை: **Q/√2**
```
