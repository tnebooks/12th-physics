**20/π² H inductor is connected to a capacitor of capacitance C. The value of C in order to impart maximum power at 50 Hz is**

```markdown
For maximum power (resonance condition): X_L = X_C

ωL = 1/(ωC)

C = 1/(ω²L)

Given:
- L = 20/π² H
- Frequency, f = 50 Hz
- ω = 2πf = 2π × 50 = 100π rad/s

C = 1/[(100π)² × (20/π²)]
C = 1/[10000π² × 20/π²]
C = 1/[10000 × 20]
C = 1/200000
C = 5 × 10⁻⁶ F = 5 μF

Therefore, the value of C is **5 μF**.

Correct answer: **5 μF**
```
