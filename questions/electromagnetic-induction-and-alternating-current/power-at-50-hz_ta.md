**20/π² H மின்தூண்டியானது மின்தேக்குத்திறன் C கொண்ட மின்தேக்கியுடன் இணைக்கப்பட்டுள்ளது. 50 Hz இல் பெருமத் திறனைச் செலுத்தத் தேவையான C இன் மதிப்பானது**

```markdown
பெருமத் திறன் (resonance) நிலையில்: X_L = X_C

ωL = 1/(ωC)

C = 1/(ω²L)

கொடுக்கப்பட்டவை:
- L = 20/π² H
- அதிர்வெண், f = 50 Hz
- ω = 2πf = 2π × 50 = 100π rad/s

C = 1/[(100π)² × (20/π²)]
C = 1/[10000π² × 20/π²]
C = 1/[10000 × 20]
C = 1/200000
C = 5 × 10⁻⁶ F = 5 μF

எனவே, C இன் மதிப்பு = **5 μF**

சரியான விடை: **5 μF**
```
