**ஒரு மின்சுற்றில் R, L, C மற்றும் AC மின்னழுத்த மூலம் ஆகிய அனைத்தும் தொடராக இணைக்கப்பட்டுள்ளன. L ஆனது சுற்றிலிருந்து நீக்கப்பட்டால், மின்னழுத்த வேறுபாடு மற்றும் மின்னோட்டம் இடையே உள்ள கட்ட வேறுபாடு π/3 ஆகும். மாறாக, C ஆனது நீக்கப்பட்டால், கட்ட வேறுபாடானது மீண்டும் π/3 என உள்ளது. சுற்றின் திறன் காரணி**

```markdown
முதல் நிலை: L நீக்கப்பட்டால் → R மற்றும் C தொடரில்:
tan φ₁ = X_C / R = tan(π/3) = √3
X_C / R = √3  ... (1)

இரண்டாம் நிலை: C நீக்கப்பட்டால் → R மற்றும் L தொடரில்:
tan φ₂ = X_L / R = tan(π/3) = √3
X_L / R = √3  ... (2)

(1) மற்றும் (2) இலிருந்து: X_L = X_C = √3 R

R, L, C அனைத்தும் தொடரில் இருக்கும் போது:
மொத்த மின்மறுப்பு Z = √[R² + (X_L - X_C)²] = √[R² + 0] = R

திறன் காரணி cos φ = R/Z = R/R = 1

எனவே, சுற்றின் திறன் காரணி = **1**

சரியான விடை: **1**
```
