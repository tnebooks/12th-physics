**In an electromagnetic wave travelling in free space the rms value of the electric field is 3 V m⁻¹. The peak value of the magnetic field is**

```markdown
For electromagnetic waves, E₀ / B₀ = c, where E₀ and B₀ are peak values.  
Given E_rms = 3 V/m.  
Peak electric field E₀ = E_rms × √2 = 3√2 V/m.  
Peak magnetic field B₀ = E₀ / c = (3√2) / (3 × 10⁸) = √2 × 10⁻⁸ T ≈ 1.414 × 10⁻⁸ T.  
Therefore, the correct answer is 1.414 × 10⁻⁸ T.
```
