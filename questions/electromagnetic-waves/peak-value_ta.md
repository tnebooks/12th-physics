**வெற்றிடத்தில் பரவும் மின்காந்த அலை ஒன்றின் மின்புலத்தின் சராசரி இருமடிமூல மதிப்பு (rms) 3 V m⁻¹. எனில் காந்தப்புலத்தின் உச்சமதிப்பு என்ன?**

```markdown
மின்காந்த அலையில், E₀ / B₀ = c (உச்ச மதிப்புகளுக்கு).  
மேலும், E_rms = E₀ / √2 → E₀ = E_rms × √2 = 3√2 V/m.  
B₀ = E₀ / c = (3√2) / (3 × 10⁸) = √2 × 10⁻⁸ T ≈ 1.414 × 10⁻⁸ T.  
எனவே, சரியான விடை 1.414 × 10⁻⁸ T.
```
