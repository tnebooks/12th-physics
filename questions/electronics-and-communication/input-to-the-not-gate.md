**If the input to the NOT gate is A = 1011, its output is**

```markdown
A NOT gate (inverter) inverts each bit of the input signal.

Given input A = 1011 (4 bits):
- Bit 1 (MSB): 1 → 0
- Bit 2: 0 → 1
- Bit 3: 1 → 0
- Bit 4 (LSB): 1 → 0

Therefore, the output is: **0100**.

Let's verify the options:
- 0011 → Incorrect
- 1100 → Incorrect (this would be the output of a buffer or no change)
- 1000 → Incorrect
- 0100 → Correct

Hence, the correct answer is **0100**.
```
