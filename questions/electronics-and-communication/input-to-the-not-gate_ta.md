**ஒரு NOT கேட்டின் உள்ளீடு A = 1011 எனில், அதன் வெளியீடானது,**

```markdown
NOT கேட் (இன்வெர்ட்டர்) ஒவ்வொரு பிட்டையும் நேர்மாறாக்கும் (0 → 1, 1 → 0).

கொடுக்கப்பட்ட உள்ளீடு A = 1011 (4 பிட்கள்):
- பிட் 1 (MSB): 1 → 0
- பிட் 2: 0 → 1
- பிட் 3: 1 → 0
- பிட் 4 (LSB): 1 → 0

எனவே, வெளியீடு: **0100**.

விடைகளைச் சரிபார்க்க:
- 0011 → தவறு
- 1100 → தவறு (இது மாற்றமில்லாத அல்லது பஃபர் வெளியீடு)
- 1000 → தவறு
- 0100 → சரி

எனவே, சரியான விடை **0100** ஆகும்.
```
