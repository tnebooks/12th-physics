choices:
  - "A < B = C < D"
  - "C < A = B < D"
  - "D > C > B > A"
answers:
  - "D < C < B < A"
---

மின்துகள்களை உள்ளடக்கிய நான்கு காஸியன் பரப்புகள் படத்தில் காட்டப்படுகின்றன. ஒவ்வொரு காஸியன் பரப்பையும் கடக்கும் மின்பாய் மதிப்புகளை தரவிரைமயில் எழுதுக.

![](./gaussian.png)


```markdown
காஸ் விதிப்படி: **மின்பாய் ∝ மொத்த உட்செலுத்தப்பட்ட மின்னூட்டம்**

படத்தில் இருந்து:
- பரப்பு A: $ +Q, +Q, -Q $ ஐ உள்ளடக்கியுள்ளது → மொத்தம் = $ +Q $
- பரப்பு B: $ +Q, +Q $ ஐ உள்ளடக்கியுள்ளது → மொத்தம் = $ +2Q $
- பரப்பு C: $ +Q, -Q, +Q, -Q $ ஐ உள்ளடக்கியுள்ளது → மொத்தம் = $ 0 $
- பரப்பு D: $ -Q, -Q $ ஐ உள்ளடக்கியுள்ளது → மொத்தம் = $ -2Q $

மின்பாயின் ஏறுவரிசை (குறியிட்ட மதிப்புகள்):
$$
\Phi_D = -2Q/\varepsilon_0 < \Phi_C = 0 < \Phi_B = +2Q/\varepsilon_0 < \Phi_A = +Q/\varepsilon_0
$$

எனவே, சரியான ஏறுவரிசை:
$$
D < C < B < A
$$

எனவே, சரியான விடை **D < C < B < A** ஆகும்.
```
