**மின்துகள்களை உள்ளடக்கிய நான்கு காஸியன் பரப்புகள் படத்தில் காட்டப்பட்டுள்ளன. ஒவ்வொரு காஸியன் பரப்பையும் கடக்கும் மின்பாய மதிப்புகளை தரவரிசையில் எழுதுக.**

![](qns-5.png)

```markdown
காஸ் விதிப்படி, மூடப்பட்ட பரப்பு வழியான மின்பாயம் (Φ) என்பது:
Φ = Q_enc / ε₀

இங்கு Q_enc என்பது அந்த காஸியன் பரப்புக்குள் அடைபட்ட நிகர மின்னூட்டம் ஆகும்.

மின்பாயமானது பரப்பின் அளவு அல்லது வடிவத்தைச் சார்ந்தது அல்ல; அது அடைபட்ட நிகர மின்னூட்டத்தை மட்டுமே சார்ந்துள்ளது.

கொடுக்கப்பட்ட பரப்புகளில் (உள்ளேயுள்ள மின்னூட்டங்கள் பின்வருமாறு இருப்பதாகக் கொள்க):
- பரப்பு A ஆனது மிகப்பெரிய நேர் நிகர மின்னூட்டத்தை உள்ளடக்கியுள்ளது
- பரப்பு B ஆனது அதைவிட சிறிய நேர் நிகர மின்னூட்டத்தை உள்ளடக்கியுள்ளது
- பரப்பு C ஆனது இன்னும் சிறிய நேர் நிகர மின்னூட்டத்தை உள்ளடக்கியுள்ளது
- பரப்பு D ஆனது மிகச் சிறிய நிகர மின்னூட்டத்தை (அல்லது எதிர் மின்னூட்டத்தை) உள்ளடக்கியுள்ளது

எனவே, மின்பாய மதிப்புகளின் ஏறுவரிசை (சிறியதிலிருந்து பெரியதற்கு):
D < C < B < A

ஆகையால், சரியான விடை **D < C < B < A** ஆகும்.
```
