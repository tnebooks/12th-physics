**$\vec{p}_m = (-0.5 \hat{i} + 0.4 \hat{j})\text{ Am}^2$ என்ற வெக்டர் மதிப்புடைய காந்த இருமுனையானது,$\vec{B} = 0.2 \hat{i}\text{ T}$ என்ற சீரான காந்தப்புலத்தில் வைக்கப்பட்டால் அதன் நிலையாற்றல் மதிப்பு**

```markdown
காந்த இருமுனையின் நிலை ஆற்றல் (Potential energy) என்பது:

U = - pm · B (திசையிலி பெருக்கல்)

pm = (-0.5 î + 0.4 ĵ) Am²
B = 0.2 î T

pm · B = (-0.5)(0.2) + (0.4)(0) = -0.1 J

U = -(-0.1) = 0.1 J

எனவே, காந்த இருமுனையின் நிலை ஆற்றல் **0.1 J** ஆகும்.

(குறிப்பு: காந்தப்புலத்துடன் இருமுனை ஒத்திசைவாக (aligned) இருக்கும்போது U = -pmB (குறைந்த ஆற்றல்), எதிர்த்திசையில் இருக்கும்போது U = +pmB (அதிக ஆற்றல்). இங்கு pm · B = -0.1 J ஆக இருப்பதால், U = +0.1 J ஆகிறது.)
```
