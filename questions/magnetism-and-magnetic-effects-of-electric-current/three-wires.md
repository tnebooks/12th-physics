**Three wires of equal lengths are bent in the form of loops. One of the loops is circle, another is a semi-circle and the third one is a square. They are placed in a uniform magnetic field and same electric current is passed through them. Which of the following loop configuration will experience greater torque?**

```markdown
The torque (τ) experienced by a current loop in a uniform magnetic field is given by:

τ = N I A B sinθ

For maximum torque, sinθ = 1 (when the plane of the loop is parallel to the magnetic field), so:

τ = N I A B

Since all loops have:
- Same length of wire (L)
- Same current (I)
- Same magnetic field (B)
- Same number of turns (N = 1)

The torque depends only on the **area (A)** enclosed by the loop. The loop with the **maximum area** for a given perimeter will experience the greatest torque.

**Step 1: Find the area for each shape with the same perimeter (L)**

Let the total length of wire be L.

**Circle:** 
Circumference = 2πr = L → r = L/(2π)
Area = πr² = π × (L/2π)² = L²/(4π)

**Square:**
Perimeter = 4a = L → a = L/4
Area = a² = L²/16

**Semi-circle:**
For a semi-circle loop (with diameter), total length = πr + 2r = L
→ r(π + 2) = L → r = L/(π + 2)
Area of semi-circle = (1/2)πr² = (1/2)π × L²/(π+2)²

**Step 2: Compare areas**

Approximate values (L = 1):
- Circle: 1/(4π) = 0.0796
- Square: 1/16 = 0.0625
- Semi-circle: (1/2)π/(π+2)² = 1.5708/(5.1416)² = 1.5708/26.43 = 0.0594

**Circle has the largest area** among all shapes for a given perimeter.

Therefore, the **circular loop** will experience the greatest torque.

So, the correct answer is **Circle**.
```
