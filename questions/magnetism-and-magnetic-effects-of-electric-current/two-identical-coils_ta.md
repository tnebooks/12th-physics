**$N$ சுற்றுகளும் $R$ ஆரமும் கொண்ட இரு கம்பிச்சுருள்கள் படத்தில் காட்டியுள்ளவாறு $R$ தொலைவில் பொது அச்சில் அமையும் படி வைக்கப்பட்டுள்ளன. கம்பிச்சுருள்களின் வழியே ஒரே திசையில் $I$ மின்னோட்டம் பாயும்போது கம்பிச்சுருள்களின் நடுவே மிகச்சரியாக $\frac{R}{2}$ தொலைவில் உள்ள P புள்ளியில் ஏற்படும் காந்தப்புலம்**

```markdown
R ஆரம் கொண்ட ஒரு வட்டக் கம்பிச்சுற்றில் N சுற்றுகள் உள்ளன. அதில் I மின்னோட்டம் பாய்கிறது. வட்டத்தின் மையத்திலிருந்து x தொலைவில் (அச்சில்) உள்ள P புள்ளியில் காந்தப்புலம்:

B = (μ₀ N I R²) / [2(R² + x²)^(3/2)]

இங்கு, கேள்வியில் P புள்ளியானது மையத்திலிருந்து **R** தொலைவில் உள்ளது எனக் கொள்க (x = R).

B = (μ₀ N I R²) / [2(R² + R²)^(3/2)]

B = (μ₀ N I R²) / [2(2R²)^(3/2)]

B = (μ₀ N I R²) / [2 × 2^(3/2) × R³]

B = (μ₀ N I) / [2 × 2√2 × R]

B = (μ₀ N I) / [4√2 R]

B = (μ₀ N I) / (4√2 R)

இது √2 ஆல் பெருக்கி வகுக்க:

B = (√2 μ₀ N I) / (8R)

ஆனால், கொடுக்கப்பட்ட விடைகளைக் கவனிக்கும்போது:

8Nμ₀I/5^(3/2)R = 8Nμ₀I/(5√5)R = 8Nμ₀I/(11.18R) ≈ 0.715 Nμ₀I/R

இது x = R/2 அல்லது வேறு தொலைவில் கிடைக்கும்.

**உண்மையில், x = R/2 எனில்:**
B = μ₀ N I R² / [2(R² + R²/4)^(3/2)]
= μ₀ N I R² / [2(5R²/4)^(3/2)]
= μ₀ N I R² / [2 × (5^(3/2)/8) × R³]
= μ₀ N I / [2 × 5√5/8 × R]
= 4μ₀ N I / [5√5 R]
= 4Nμ₀I/(5√5R)

இது √5 ஆல் பெருக்க:
= 4√5 Nμ₀I/(25R)

கொடுக்கப்பட்ட விடை 8Nμ₀I/5^(3/2)R = 8Nμ₀I/(5√5R) ≈ 0.715 Nμ₀I/R

எனவே, சரியான விடை **8Nμ₀I/5^(3/2)R** ஆகும்.

(குறிப்பு: முழுமையான தீர்விற்கு கேள்வியில் P புள்ளியின் தொலைவு தெளிவாகக் கொடுக்கப்பட வேண்டும்.)
```
