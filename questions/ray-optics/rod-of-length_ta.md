**10 cm நீளமுடைய தண்டு ஒன்று, 10 cm குவியத்தூரம் கொண்ட குழி ஆடியின் முதன்மை அச்சில் வைக்கப்பட்டுள்ளது. தண்டின் ஒரு முனை குழி ஆடியின் முனையிலிருந்து 20 cm தொலைவில் இருந்தால், கிடைக்கும் பிம்பத்தின் நீளம் என்ன?**

```markdown
குழி ஆடியின் (Concave mirror) குவியத்தூரம், $f = -10\text{ cm}$ (குறியீட்டு மரபின்படி எதிர்குறி).

தண்டின் ஒரு முனை உள்ள தொலைவு $20\text{ cm}$ எனில், அது ஆடியின் வளைவு மையத்தில் ($C = 2f$) அமைந்துள்ளது. தண்டின் நீளம் $10\text{ cm}$. எனவே, தண்டின் மறுமுனை $20\text{ cm}$-க்கும் அப்பால் (அதாவது $20\text{ cm} + 10\text{ cm} = 30\text{ cm}$) வைக்கப்பட்டுள்ளது எனக் கொள்ள வேண்டும் (ஏனெனில் $10\text{ cm}$-ல் வைத்தால் பிம்பம் ஈறிலாத் தொலைவை அடையும்).

* **முனை 1-இன் நிலை ($u_1$):** $u_1 = -20\text{ cm}$
* **முனை 2-இன் நிலை ($u_2$):** $u_2 = -30\text{ cm}$

ஆடிச் சமன்பாட்டைப் பயன்படுத்தி ($\frac{1}{v} + \frac{1}{u} = \frac{1}{f}$) இரண்டு முனைகளின் பிம்பம் உருவாகும் இடங்களைக் கண்டறிவோம்:

**1. முனை 1-இன் பிம்பம் ($v_1$):**
$$\frac{1}{v_1} + \frac{1}{-20} = \frac{1}{-10}$$
$$\frac{1}{v_1} = \frac{1}{20} - \frac{1}{10} = \frac{1 - 2}{20} = -\frac{1}{20}$$
$$v_1 = -20\text{ cm}$$
(பொருள் வளைவு மையத்தில் ($C$) இருப்பதால் பிம்பமும் அதே இடத்திலேயே உருவாகிறது).

**2. முனை 2-இன் பிம்பம் ($v_2$):**
$$\frac{1}{v_2} + \frac{1}{-30} = \frac{1}{-10}$$
$$\frac{1}{v_2} = \frac{1}{30} - \frac{1}{10} = \frac{1 - 3}{30} = -\frac{2}{30} = -\frac{1}{15}$$
$$v_2 = -15\text{ cm}$$

**பிம்பத்தின் நீளம்:**
பிம்பத்தின் நீளம் என்பது பிம்பத்தின் இரண்டு முனைகளுக்கும் இடையேயான தொலைவு ஆகும்.
$$\text{பிம்பத்தின் நீளம்} = |v_2 - v_1|$$
$$\text{பிம்பத்தின் நீளம்} = |-15 - (-20)| = |-15 + 20| = 5\text{ cm}$$

எனவே, கிடைக்கும் பிம்பத்தின் நீளம் **5 cm** ஆகும்.

```
