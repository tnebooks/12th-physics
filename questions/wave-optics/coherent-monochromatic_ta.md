**I மற்றும் 4I ஒளிச்செறிவுகள் கொண்ட இரண்டு ஒற்றை நிற ஓரியல் ஒளிக்கற்றைகள் ஒன்றுடன் ஒன்று மேற்பொருந்துகின்றன. தொகுபயன் பிம்பத்தின் சாத்தியமான பெரும மற்றும் சிறும ஒளிச்செறிவுகள் முறையே**

```markdown
இரண்டு ஒளிக்கற்றைகள் குறுக்கீடு செய்யும்போது, அதிகபட்ச மற்றும் குறைந்தபட்ச ஒளிச்சக்திகள் பின்வருமாறு வழங்கப்படுகின்றன:

$$I_{\text{max}} = (\sqrt{I_1} + \sqrt{I_2})^2$$

$$I_{\text{min}} = (\sqrt{I_1} - \sqrt{I_2})^2$$

கொடுக்கப்பட்டவை:

* $I_1 = I$
* $I_2 = 4I$

$$I_{\text{max}} = (\sqrt{I} + \sqrt{4I})^2 = (\sqrt{I} + 2\sqrt{I})^2 = (3\sqrt{I})^2 = 9I$$

$$I_{\text{min}} = (\sqrt{I} - \sqrt{4I})^2 = (\sqrt{I} - 2\sqrt{I})^2 = (-\sqrt{I})^2 = I$$

எனவே, அதிகபட்ச ஒளிச்சக்தி $9I$ மற்றும் குறைந்தபட்ச ஒளிச்சக்தி $I$ ஆகும்.

சரியான விடை: **$9I$ மற்றும் $I$**.
```
